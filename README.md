# MULTISPORTS SCORING

**MULTISPORTS SCORING** is a free Android and Web/PWA application for sports scoring, statistics, player profiles and performance tracking.

It brings together multiple sports and performance tools in a single application, with dedicated experiences for **Darts, Foosball / Table Football, Pétanque, Running and Fitness**.

- Official Web app: [https://multisports-scoring.pages.dev/](https://multisports-scoring.pages.dev/)
- Google Play package: `com.multisportsscoring.app`
- Google Play: [https://play.google.com/store/apps/details?id=com.multisportsscoring.app](https://play.google.com/store/apps/details?id=com.multisportsscoring.app)
- Platforms: Android + Web / PWA
- Languages: **22 languages supported**

---

## Sports & features

### 🎯 Darts

MULTISPORTS SCORING includes a complete **dart counter, darts scoring, scoreboard and statistics environment**.

Supported experiences include:

- **X01 — 301 / 501 / 701 / 901**
- **Cricket**
- **Killer**
- **Shanghai**
- **Challenge**
- **Darts Poker**
- **CRADOS**
- **Gros 6**
- Training modes
- Classic games
- Variants
- Original MULTISPORTS SCORING game modes

The Darts module also provides:

- Player profiles
- Match history
- Detailed statistics
- Records
- Score tracking
- Local games
- Online features
- Leaderboards
- Competitions
- Match resume / recovery
- Multi-player support

MULTISPORTS SCORING can therefore be used as a **free darts counter**, **X01 scorer**, **darts scoreboard** and **darts statistics application** on smartphone, tablet and Web/PWA.

---

### ⚽ Foosball / Table Football

The application includes scoring and match-management tools for **foosball / table football**.

Players can use MULTISPORTS SCORING to manage scores and matches while keeping their sports activities inside the same application ecosystem.

---

### 🟠 Pétanque

MULTISPORTS SCORING also includes dedicated scoring tools for **pétanque**.

The application provides a simple way to manage games, players and results while keeping activity inside the same multisport platform.

---

### 🏃 Running Performance

The **Running Performance** module supports:

- GPS route tracking
- Distance
- Duration
- Pace
- Kilometre splits
- Saved sessions
- Running history
- Performance statistics
- Route and activity analysis

Running Performance extends MULTISPORTS SCORING beyond scorekeeping into personal sports-performance tracking.

---

### 💪 Fitness Performance

The **Fitness Performance** module provides workout and strength-training tools including:

- Workout sessions
- Exercise library
- Free training sessions
- Rest timer
- Training history
- Training volume
- Personal records
- 1RM tracking
- Progress statistics
- Performance analysis

This allows MULTISPORTS SCORING to combine traditional sports scoring with fitness and physical-performance tracking.
