# FIT PERF — AWENA media approval library

Generated AWENA media is now approval-gated. The application never renders raw generation output.

Directories:

- `/fit/awena-library/review/<assetKey>/` — generated media waiting for human validation.
- `/fit/awena-library/approved/<assetKey>/` — the only generated media that the application may render.
- `/fit/awena-library/rejected/<assetKey>/` — failed/rejected generations kept for diagnosis.
- legacy `/fit/awena-library/<assetKey>/` folders are treated as REVIEW and can be quarantined with `npm run fit:awena:registry -- --migrate-legacy`.

Hand-authored AWENA media under `/fit/motions/awena/premium/` and `/fit/exercise-media/` is authoritative and is never regenerated by default.

A generated video creates only:

- `awena-preview.webm` — transparent AWENA demonstration loop.
- `awena-poster.webp` — poster.
- `review-keyframes/candidate-01.webp` … `candidate-04.webp` — visual inspection aids only. They are NOT pedagogical steps.
- `metadata.json` — provenance, QA metrics and REVIEW/REJECTED state.

The final `awena-step-01.webp` … `awena-step-04.webp` files must come from the dedicated step-image workflow and be explicitly marked READY before a generated pack can be APPROVED.

Useful commands:

- `npm run fit:awena:registry`
- `npm run fit:awena:queue -- --refresh`
- `npm run fit:awena:run -- --limit 1`
- `npm run fit:awena:steps:queue`
- `npm run fit:awena:steps:ready -- --asset <assetKey>`
- `npm run fit:awena:review -- --asset <assetKey> --approve`
- `npm run fit:awena:review -- --asset <assetKey> --reject`
- `npm run fit:awena:index`
- `npm run fit:awena:audit`

V113 completeness rules:

- `APPROVED COMPLETE` = video + poster + at least 4 validated pedagogical steps; never regenerated.
- `APPROVED PARTIAL` = validated media exists but one or more components are missing.
- Motion queue may create `VIDEO_ONLY_SUPPLEMENT` only when an APPROVED PARTIAL pack lacks video.
- Step queue may create `STEPS_ONLY_SUPPLEMENT` only when an authoritative video already exists and fewer than 4 validated steps are available.
- Component approval copies only missing pieces into generated `/approved`; already validated components are protected against overwrite.
