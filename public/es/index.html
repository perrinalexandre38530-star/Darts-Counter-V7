Preguntas frecuentes

Respuestas rápidas sobre la aplicación.

¿Qué es MULTISPORTS SCORING?

MULTISPORTS SCORING es una aplicación Android y Web para marcadores deportivos, estadísticas y seguimiento del rendimiento.

¿Qué deportes están disponibles en la aplicación?

Las páginas públicas incluyen dardos, running con GPS, petanca y futbolín.

¿Qué modos de dardos son compatibles?

La aplicación incluye X01 con 301, 501, 701 y 901, además de Cricket, Killer y Shanghai.

¿Qué datos registra Running Performance?

Running Performance registra la ruta GPS, la distancia, el tiempo, el ritmo, los splits y el historial de sesiones.
