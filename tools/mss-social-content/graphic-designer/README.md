## PC Windows
1. Décompresser le patch à la racine V7(49). `MSS_GRAPHIC_DESIGNER_OUVRIR.cmd` lance la galerie sur 127.0.0.1:4186 (Node déjà utilisé par AI CONTROL). Aucune installation Python nécessaire pour contrôler les PNG déjà livrés.
2. Cliquez sur chaque affiche pour contrôler la traduction et le visuel; Valider / Rejeter. La décision est enregistrée localement dans `output/approvals.json`, pour le hash exact. Ne pas valider des affiches dont les droits ou les promesses produit n'ont pas été vérifiés.
3. Pour générer à nouveau : installer Python 3.11+ puis exécuter `MSS_GRAPHIC_DESIGNER_INSTALLER.cmd`. Installer les polices Noto Sans Bold, Noto Sans CJK Bold (JP et SC), DejaVu Sans Bold (arabe), FreeSans Bold (hindi) depuis leurs distributions officielles. Aucun fichier de police fourni. Sur Windows définir les variables MSS_FONT_LATIN, MSS_FONT_AR, MSS_FONT_HI, MSS_FONT_JA, MSS_FONT_ZH avec le chemin absolu des fichiers si la détection échoue. Pour les collections TTC, MSS_FONT_INDEX_JA et MSS_FONT_INDEX_ZH déterminent l'index (0 et 2 pour NotoSansCJK-Bold.ttc; avec variables explicites définir les index). Pillow doit disposer de RAQM; absence de police/glyphes/RAQM bloque le rendu concerné. Sur Linux fontconfig détecte les familles.
4. `MSS_GRAPHIC_DESIGNER_GENERER.cmd` rend toutes les langues. Pour un seul lot : `.venv\Scripts\python.exe designer.py render --lang en --campaign campaign_02`. Les modifications de hash invalidant une validation, vérifier à nouveau après changement.

## Contrat robot
`node tools/mss-social-content/graphic-designer/media-gate.mjs en campaign_02` retourne un JSON contenant le chemin absolu, la légende, l'identifiant, la langue, le hash et le lien QR, uniquement si ce fichier exact a été validé. Échec non nul sinon. En JS : `import {selectMedia} from './media-gate.mjs'` (adapter le chemin). Ne jamais contourner cette porte en sélectionnant directement les masters ou les fichiers `output/`. Ne pas envoyer dans une langue de secours. Sélection et rendu ne font aucun appel IA ni publication. Le robot X de V7(49) ne gère que le profil; un adaptateur de publication reste nécessaire pour chaque canal, avec compte autorisé, limites de fréquence, déduplication et politiques de plateforme. Aucune dépense ni publication exécutée. Les formats et droits de diffusion doivent être vérifiés au moment de l'envoi.

## QA
`python designer.py verify` vérifie la présence des 66 entrées et l'intégrité SHA. Au rendu, la taille des textes, la couverture Unicode et le QR décodé sont contrôlés. Cela ne certifie pas la traduction ni le graphisme; validation humaine obligatoire. Le catalogue n'autorise aucune diffusion par défaut. Les sources du moteur et les fichiers de campagne sont séparés de l'application Android/TV : aucun changement package.json ni assets runtime.
