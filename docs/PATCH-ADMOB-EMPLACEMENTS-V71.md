# Patch AdMob — emplacements supplémentaires V71

Ajouts sûrs (bannières intégrées dans le flux, hors gameplay) :

- JEUX Fléchettes : hub / favoris / tous les jeux ;
- TRAINING : sous le ticker header ;
- ONLINE : sous le grand header profil ;
- HOME Pétanque ;
- HOME Ping-Pong ;
- HOME Baby-Foot ;
- HOME Mölkky ;
- HOME Dice ;
- Compétitions : liste / reprise / historique ;
- Compétition : vue d'un tournoi ;
- Historique StatsHub.

Aucun emplacement ajouté dans les écrans de jeu, de saisie de score ou de configuration afin d'éviter les clics accidentels et la gêne pendant une partie.

Le patch conserve la configuration AdMob existante de V71. Les appareils déclarés comme appareils de test dans la console AdMob continuent de recevoir des annonces de test.
